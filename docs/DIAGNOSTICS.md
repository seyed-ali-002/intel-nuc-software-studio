# Diagnostics

A diagnostic run should collect only relevant technical information.

Sections:
1. System
2. Hardware
3. Kernel
4. Drivers/modules
5. Capabilities
6. Backends
7. Permissions
8. Sensors
9. Battery
10. Lighting
11. NVIDIA
12. Recent application errors

Sensitive data such as usernames, home paths, network addresses and serial numbers should be redacted by default.

The report must be useful for troubleshooting without requiring users to expose private information.
